# Lattice 产品定义

## 一句话

Lattice 是一个**离线优先、只读、多语言的源码实现阅读平台**：把语言实现和标准库整理成不可变 Source Pack，用统一的文件树、符号搜索、跳转、调用链、类型关系和版本对比来阅读真实源码。

它不是代码编辑器、IDE、通用仓库分析器，也不是课程平台。

## 目标

1. 把 CPython、OpenJDK、Rust、TypeScript、SQLite、Nginx、Spring Boot、Vue、React 等真实实现整理成本地源码包。
2. 让同一套阅读操作适用于不同语言：文件树、标签页、语义高亮、符号大纲、定义跳转、引用、调用链、依赖图和版本 Diff。
3. 在类型层面提供**继承 / 实现关系**：直接基类、接口、Trait，以及跨文件的派生类型和实现者。
4. 全部内容可离线使用；阅读期间不访问网络。
5. 源码包只读、不可变、带版本与来源；升级等价于安装新版本。

## 核心体验

### 本地源码书库

- 按实现和版本浏览、切换、导入、卸载 Source Pack。
- 多版本可以并存，用于同一文件的跨版本对比。
- 书库、侧栏、文件头、文件信息和状态栏始终显示版本。
- 支持目录与 ZIP 导入，校验文件结构与可选 checksum，导入可取消。

### 源码阅读

- tree-sitter 语义高亮。
- 文件内符号大纲，按类、模块、命名空间、`impl` / `trait` 等容器分组。
- 多标签页、前进/后退历史、文件内查找、全局文件/符号搜索。
- 双击标识符跨文件查找定义。
- 语义引用扫描，排除注释、字符串和条件编译噪声。
- 代码折叠、可见行虚拟滚动、跳转时自动展开。
- 四套主题与 80%–200% 全局缩放。

### 关系理解

- 直接调用者与被调用函数。
- 多层调用树，按需展开。
- 文件级导入/包含依赖与反向依赖。
- 模块依赖列表和关系图。
- 同一实现的跨版本逐行 Diff 与符号级新增/删除/修改摘要。
- 类型继承/实现关系：直接基类、接口、Trait 或 C++ 基类；跨文件派生类型和实现者。
- 未解析的关系明确显示为未解析，不用猜测补齐。

### 本地注释翻译

- 选中源码注释后，用本地 OPUS-MT 模型翻译成中文。
- 独立 `lattice-translator.exe`，按需启动，断网可用。
- 支持取消、截断提示、错误状态和请求匹配。
- 当前固定为英语 → 简体中文，单一模型；不作为后续扩展重点。

## 明确不做

以下功能已从产品目标中移除，不再进入路线图：

- 书签、本地笔记、阅读进度。
- 外部 Markdown 指南导入、符号锚点与指南迁移。
- 用户私有仓库的通用索引、代码编辑、调试、构建任务或完整 IDE。
- 内建课程、官方固定学习路径、内容运营。
- 在线翻译、远程 AI、模型市场、多模型管理、更多语言对。
- 自定义主题导入。
- 多文件/整包 Diff。
- 正则搜索、全词匹配、多窗口/分屏。
- 界面国际化、自动更新。
- Native/Blitz 后端的完整功能对齐；该后端仅保留为实验入口。

## 数据与离线

| 数据 | 性质 | 处理 |
| --- | --- | --- |
| Source Pack 源码 | 不可变内容 | 丢失后从安装介质恢复或重新获取 |
| 符号/文档索引 | 可重建投影 | 删除后自动重建 |
| 会话配置、主题、窗口几何 | 本地偏好 | 位于 `%APPDATA%\Lattice`，可删除 |
| 翻译模型 | 可选本地资源 | 不随主程序分发，可重新下载 |

不保存用户笔记或指南，因此不存在笔记与源码版本迁移问题。

## 验收标准

- 断网启动、打开源码、搜索、跳转、查看关系、翻译均可用。
- Nginx、Spring Boot、Vue、React 真实源码包可以导入、建索引并正常阅读。
- Java、JavaScript、TypeScript、C++、Rust 的类型继承/实现关系可以在当前文件和跨文件场景中展示。
- 索引构建和文件解析不阻塞 UI。
- 不出现无来源、无版本的源码内容。
