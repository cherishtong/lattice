## 后续原则

1. 先把源码浏览、搜索和跳转做扎实，再扩语言数量。
2. 平台不生产固定课程；外部指南必须与源码修订绑定，不使用漂浮的旧行号。
3. 搜索、符号图与 Diff 是源码理解工具，不是内容运营工具。
4. 用户笔记与指南是本地学习资产，不属于可删除缓存。
5. 每个里程碑都必须断网验证。
