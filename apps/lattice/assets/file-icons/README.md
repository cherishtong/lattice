# Material Icon Theme

The SVG files in this directory are vendored from **Material Icon Theme v5.39.0**:

- Source: https://github.com/material-extensions/vscode-material-icon-theme
- License: MIT (see `LICENSE`)
- Integration: `apps/lattice/src/file_icons.rs`, generated by `scripts/vendor-file-icons.mjs`

The full 1,251-icon file/folder set is embedded into the application at compile time.
`file_icons.rs` uses Material Icon Theme's filename, extension and folder-name
associations, including light variants where the theme provides them.
